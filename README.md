# safi-reference

Signed reference data for the Safi (صافي) app: official fuel prices, platform defaults and
vehicle templates.

- `reference-data.json` is a signed envelope (Ed25519 over the exact `payload` string). The app
  accepts it only if the signature verifies with a key built into the app and the payload
  `version` is newer than the one it has.
- Phones fetch it at most once every 24 hours from
  `https://raw.githubusercontent.com/mSalamaSleem/safi-reference/main/reference-data.json`.
- Do not edit this file by hand: a changed payload without a new signature is rejected. Update it
  with the signing tool in the app repository, then commit here.

Fuel prices come from the decisions of Egypt's fuel pricing committee (لجنة التسعير التلقائي
للمنتجات البترولية), each entry with its date and source link.
